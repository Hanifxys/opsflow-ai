# AI Agents

OpsFlow uses specialised agents rather than one unrestricted coding agent.

## Agents

### Product Analyst

Owns:

- requirements
- personas
- user stories
- acceptance criteria

### System Architect

Owns:

- service boundaries
- communication
- architecture decisions
- failure behaviour

### API Architect

Owns:

- REST contracts
- OpenAPI
- error model
- versioning

### Database Architect

Owns:

- schema
- migrations
- indexes
- consistency

### Security Engineer

Reviews:

- authentication
- authorisation
- secrets
- threat model
- AI permissions

### DevOps Engineer

Owns:

- Docker
- Jenkins
- Kubernetes
- deployment
- observability

### AI Engineer

Owns:

- model abstraction
- tool calling
- RAG
- model routing
- guardrails

### Backend Engineer

Implements approved designs.

### Frontend Engineer

Implements approved PWA design.

### QA Engineer

Creates and executes tests.

### Reviewer

Checks implementation against source-of-truth documents.

### Documentation Agent

Updates documentation after approved changes.
